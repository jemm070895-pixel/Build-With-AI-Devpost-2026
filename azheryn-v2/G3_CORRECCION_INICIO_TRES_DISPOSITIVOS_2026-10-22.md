# G3 — Arranque en laptop, teléfono y tableta

El lanzador Wi-Fi ahora comprueba Vite, React y TypeScript antes de iniciar. Si faltan paquetes, ejecuta `npm ci`. Antes solo comprobaba Vite, lo que podía dejar una instalación incompleta.

Las tres pantallas usan la misma web en la red local, pero las partidas **no se sincronizan automáticamente**. El teléfono y la tableta necesitan la laptop encendida y el servidor abierto.

No se afirma compilación completa ni validación en hardware: todavía están pendientes.
