**Important:** This policy document is not a substitute for file-by-file licensing. MIT must be attached to an unambiguously defined code scope (e.g., a dedicated `demo-code/` directory with its own `LICENSE` and assets excluded), and any code or media actually licensed under MIT cannot later be unilaterally withdrawn from copies already licensed. Before publication, audit embedded narrative strings, bundled images, audio, fonts, and third-party materials. A blanket root MIT LICENSE over mixed code and reserved assets can create ambiguity. Source releases must distinguish open-source code from reserved materials and provide a usable way to build/test the demo under the applicable asset permissions.
