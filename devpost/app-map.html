AZHERYN V2 — Code Tour and App Map

Chapter 1 · G6.31.1 · 23 October 2026

Core journey

Start the game → read the prologue → guide Mui and seven guards → select trees and collect logs → place a building → finish the 91-log storehouse → see the epilogue.

Source map

  • azheryn-v2/src/main.tsx — React entry point
  • src/App.tsx — application shell
  • src/ui/IntroStory.tsx — prologue and story presentation
  • src/ui/WorldView.tsx — main game interaction and interface
  • src/world/terrain.ts, noise.ts, renderer.ts, camera.ts — map generation and rendering
  • src/world/treeSpecies.ts, treeFruits.ts — tree varieties and fruit distribution
  • src/world/work.ts, storehouse.ts, materialPlanner.ts — labor, hauling and construction rules
  • src/world/climate.ts, peacefulWildlife.ts — environment systems
  • src/world/socialLife.ts, characterHistories.ts — character behavior and dialogue
  • src/world/saveSlots.ts, saveRecovery.ts, saveTransfer.ts — save management
  • src/foundation/meta0.ts — foundation contracts for later systems

How to run

From azheryn-v2/, install dependencies with npm ci and run npm run dev; production build: npm run build. The private Windows package also contains a double-click launcher.
