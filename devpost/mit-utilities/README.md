# MIT utilities — independent code release

Reusable TypeScript procedural-noise functions extracted from the Chapter 1 game: clamp, lerp, smoothstep, hash2 and fbm. No narrative or art assets.

This folder is an **independent code example**, not the complete G6.31.1 contest game. The private game and its narrative/media remain separately controlled.

Run the included smoke test with Node.js 22.16+:

`node --experimental-strip-types test/smoke.mjs`
